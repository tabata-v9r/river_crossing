📖 パズルのルールと状態表現

1. 状態の文字列表現（モデル化）

4つの登場キャラクターの位置を4文字のアルファベットで表します。

  • n / N : 人 (Navigator) 🧑
  • w / W : 狼 (Wolf) 🐺
  • c / C : キャベツ (Cabbage) 🥬
  • g / G : ヤギ (Goat) 🐐

※ 小文字は手前の岸(A)、大文字は対岸(B)にいることを表します。初期状態は nwcg、目標状態は NWCG です。

2. ボートの移動ルール

  • ボートを操縦できるのは人(n/N)だけです。
  • ボートには人の他に最大1つまで（狼・キャベツ・ヤギのいずれか）を乗せることができます。人だけで移動することも可能です。

3. 制約条件（禁止状態）

人がいない岸に以下の組み合わせが残ると失敗になります。

  • 狼とヤギが揃う（例：Nwcg, nWcG など）
  • ヤギとキャベツが揃う（例：NwcG, nwCg など）
